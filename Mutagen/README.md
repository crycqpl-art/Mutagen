# Mutagen

Sample mutation effect (VST3 / AU) built with JUCE: a 16-step Gross-Beat-style
playback sequencer, a granular chord cloud, a spectral smear/freeze, filter and
reverb. See `INSTRUKCJA.md` (Polish) for usage and installation.

Builds for Windows and macOS run automatically in GitHub Actions
(`.github/workflows/build.yml`); download the result from the run's Artifacts.
